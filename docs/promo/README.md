# Изображения для публикации

- [Telegram, RU](../assets/persona-weaver-telegram-ru.png) — постер 1600 × 2000.
- [GitHub, RU](../assets/persona-weaver-github-ru.png) — обзор для русского README.
- [GitHub, EN](../assets/persona-weaver-github-en.png) — английские пояснения вокруг русского интерфейса; локализация приложения не имитируется.

Снимки собраны из компонентов настоящих `index.js`, `ui.mjs` и `style.css` на изолированном стенде из `tests/browser.mjs`. Персона, лорбук и ответы модели — демонстрационные данные. Живые чаты, настройки, ключи и реальные API не используются. Компоненты вынесены в отдельные карточки; у находки скрыты второстепенные настройки, у автоматизации — служебный статус и кнопка сброса. Исходные снимки находятся в `docs/assets/screens`.

Генератор `generate.mjs` повторно снимает интерфейс и собирает PNG средствами браузера. Нужна установленная для браузерных проверок связка Playwright + Firefox, без новых зависимостей расширения:

```sh
node docs/promo/generate.mjs
```

Если Playwright не доступен обычным импортом, используйте переменные `PERSONA_CANON_PLAYWRIGHT_MODULE` и `PERSONA_CANON_FIREFOX`, как в [описании проверок](../testing.md).

Изображения автоматически не публикуются. Генератор не меняет публичность репозитория и не отправляет сообщения в Telegram.
